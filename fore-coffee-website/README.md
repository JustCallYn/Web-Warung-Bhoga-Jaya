# Fore Coffee — Fresh Moments

Website konsep responsif berdasarkan [desain Figma](https://www.figma.com/design/QZ0vS5ddZWTt6DIE7nmH93).

## Cara membuka

Buka **index.html** di browser. File tersebut adalah versi standalone: HTML, CSS, JavaScript, logo dan gambar sudah disertakan di dalamnya (tidak perlu instalasi atau build).

## Fitur

- Halaman utama dan navigasi responsif
- Hero dengan kopi Fore, menu tiga minuman, foto biji kopi dan cerita brand
- Informasi lokasi, banner aplikasi, dan footer dengan kontak
- Menu seluler dan dialog detail produk

## Catatan

Ini adalah **proyek konsep independen, bukan website resmi Fore Coffee**. Foto produk adalah gambar AI, dan harga menu merupakan ilustrasi. Sebelum diterbitkan untuk publik atau penggunaan komersial, pastikan izin merek serta akurasi harga dan informasi.

## Publikasi

Proyek ini saat ini disimpan dalam subfolder `fore-coffee-website/` pada repository `Web-Warung-Bhoga-Jaya`. Belum diaktifkan sebagai GitHub Pages. Agar tersedia di internet, Anda dapat memakai GitHub Pages melalui workflow yang menerbitkan isi subfolder tersebut, atau memindahkannya ke root repository khusus Fore Coffee.
